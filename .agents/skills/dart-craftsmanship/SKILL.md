# Estilo y análisis Dart

1. Sigue `analysis_options.yaml` y las convenciones del código circundante; aplica nombres Dart idiomáticos, responsabilidad clara y control de flujo legible.
2. Prefiere funciones pequeñas y retornos tempranos cuando mejoren la lectura; evita imponer límites numéricos como reglas absolutas.
3. Resuelve los problemas de análisis relevantes y revisa el alcance antes de ejecutar herramientas que puedan modificar archivos.

## Referencias

- Para SOLID, nomenclatura, control de flujo y ejemplos completos, lee [clean-code.md](references/clean-code.md).
- Para la tabla de lints, el orden de miembros y el flujo original de verificación, lee [analysis.md](references/analysis.md).
